# Flash AI 🚀

### Full Stack Agentic AI Platform with RAG & Multi-Mode AI Assistance

Flash AI is a modern full-stack AI platform built to combine conversational AI, research workflows, and document intelligence into one seamless experience.

The platform supports intelligent chat interactions, AI-powered research assistance, and Retrieval-Augmented Generation (RAG) for PDF-based question answering using advanced agentic AI workflows.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash id="d3jbn7"
git clone https://github.com/sparsh0913/flash-ai-support-agent.git
cd flash-ai-support-agent
```

---

## 2️⃣ Frontend Setup

```bash id="lj5dzn"
cd Frontend
npm install
npm run dev
```

---

## 3️⃣ Backend Setup

```bash id="nmyb9f"
cd Backend
npm install
npm start
```

---

## 4️⃣ RAG Service Setup

```bash id="xv1g5n"
cd rag-service
npm install
npm start
```

---

# 🔑 Environment Variables

Create `.env` files in required folders.

---

## Backend `.env`

```env id="j9n4y6"
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
GROQ_API_KEY=your_groq_api_key
```

---

## RAG Service `.env`

```env id="4z2mka"
GROQ_API_KEY=your_groq_api_key
LANGCHAIN_API_KEY=your_langchain_api_key
LANGCHAIN_TRACING_V2=true
LANGCHAIN_PROJECT=FlashAI
```
